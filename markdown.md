## ¿Qué es Markdown?

Markdown es un lenguaje de marcado ligero que permite dar formato a un texto plano usando símbolos sencillos en lugar de botones o menús complejos. Fue creado en 2004 por John Gruber y Aaron Swartz con el objetivo de que el texto sea fácil de leer y escribir tanto en su forma original como después de convertirse a HTML.

## Características principales

> * Sencillez: Utiliza símbolos intuitivos del teclado (como *, #, -) que se aprenden en pocos minutos.
> * Texto plano: Los archivos se guardan con la extensión .md, lo que significa que se pueden abrir, leer y editar en cualquier bloc de notas básico sin necesidad de programas especiales.
> * Compatibilidad universal: Al ser texto puro, no se corrompe con el tiempo y es compatible con cualquier sistema operativo (Windows, Mac, Linux, iOS, Android).
> * Conversión a HTML: Está diseñado para transformarse de forma automática en código web estructurado y limpio.
> * Independencia del diseño: Te permite concentrarte exclusivamente en el contenido y la estructura del texto, dejando el diseño visual (colores, tipografías) para una etapa posterior.
> * Legibilidad: El texto original (sin renderizar) sigue siendo perfectamente legible y ordenado para un ser humano.
