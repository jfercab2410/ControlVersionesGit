## ¿Qué es Git?

Git es un sistema de control de versiones distribuido y gratuito que permite registrar todos los cambios realizados en el código fuente de un proyecto a lo largo del tiempo. 

## Características principales

> * Distribuido: Cada programador tiene una copia completa del repositorio y de su historial de cambios en su propia computadora, lo que permite trabajar sin conexión a internet.
> * Historial y seguridad: Guarda "instantáneas" (llamadas commits) de los archivos. Si algo falla, es posible volver atrás en el tiempo a una versión anterior y segura del código.
> * Ramas (Branches): Permite crear líneas de trabajo independientes para probar nuevas funciones o corregir errores sin afectar la versión principal del proyecto.
